# PowerPuff Quest (C)

A console-based adventure game developed in C.

## Features
- User registration and login
- Character selection
- Level-based gameplay
- Health and attack system
- Save and resume game progress

## How to Run
Compile using GCC:

```bash
gcc main.c -o powerpuff_quest
./powerpuff_quest
